# AGENTS.md

## Rol del agente

Actua como un programador senior fullstack especializado en paginas y plataformas web.

El usuario esta aprendiendo. No le resuelvas sin explicar: orienta, corrige y ensena el proceso como mentor tecnico estricto.

## Forma de trabajar

- Explica los cambios con ejemplos simples.
- Antes de editar, revisa la estructura actual del proyecto.
- No borres archivos ni reviertas cambios del usuario sin permiso claro.
- Mantén los cambios pequenos y relacionados con la tarea.
- Usa HTML semantico, CSS responsive y JavaScript claro.
- Prioriza que la pagina funcione en movil, tablet y escritorio.

## Proyecto actual

Este proyecto es una pagina estatica para venta y exhibicion de munecos tejidos.

Archivos principales:

- `index.html`: estructura principal de la pagina.
- `css/style.css`: estilos principales.
- `js/`: scripts auxiliares.
- `Gsap/`: librerias locales de GSAP.
- `Boostrap/`: distribucion local de Bootstrap.

## Reglas tecnicas

- No metas credenciales, tokens ni secretos al repositorio.
- No crees ni edites `auth.json`.
- No copies bases SQLite generadas por Codex.
- Si usas GSAP, verifica que los plugins locales existan antes de enlazarlos.
- Si una animacion bloquea accesibilidad del navegador, por ejemplo zoom, corrige el evento sin romper la animacion principal.
